3. บันทึกไฟล์ → กด "เลือกไฟล์" นำเข้า

ตั้งค่า Firebase Firestore
วิธีรับ Firebase Config:
1. ไปที่ console.firebase.google.com
2. สร้างโปรเจกต์ใหม่ → เพิ่ม Web App (</>)
3. คัดลอก config มาวางด้านล่าง
4. ไปที่ Firestore Database → สร้าง database (test mode)
5. กด "บันทึกและเชื่อมต่อ"
